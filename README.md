A compact chess engine in 4 KB of Python (4,070 bytes): 0x88 board, negamax with alpha-beta pruning, transposition table, quiescence search, late move reduction and null-move pruning, with piece-square evaluation. Practice Elo ~1,654 on the kit's practice trial (floor to enter the final: 1,154).

## Run it

```sh
python3 -P -s main.py
```
